## 一、Rust Web 版（生产：canopies-moment.pages.dev）

### 1.1 架构转向与主体落地

- **方案 B 定案（2026-11-21）**：弃 Flutter 路线，改 Rust Core +
  Dioxus DOM Web + 原生移动 UI 的三段结构；文档格式一度冻结，
  2026-11-24 改判为可按 Rust 最优形态重构、存量走迁移。
- **主体四批落地**：core/storage（文档模型、ZIP 校验导入、
  SQLite 索引与 FTS5 trigram 中文检索，真实备份往返无损实证）、
  Dioxus 五页主体（列表/编辑/设置/备份/诊断）、根治对齐批、
  外围细节批——生产前记录见 CHANGELOG「Rust Web 重构」节。
- **仓库改名（2026-11-25）**：Overtrees/Mynote → Overtrees/Moment；
  原版整栈同日退役移出仓库（仓外只读归档），行为规格沉淀进
  《设计规范》与 docs 两份原版规范（`rename_to_moment.md`）。

### 1.2 机制建设

- **SQLite 三阶段（2026-11-25 全过）**：rusqlite + SAHPool VFS +
  存储 Worker 化、附件留 OPFS 文件式、IDB 保留副本；阶段三为
  双写观察期（差量镜像、硬失败自动只读降级 + 横幅、后端开关可
  回滚），退出判据 ≥14 天且 ≥30 次冷启对账全等（`audit_sqlite_integration.md`）。
- **救援层（2026-11-24 上线，生产 7cc10b87d8）**：index.html 内联
  外壳——状态快照环、12 秒看门狗救援条、救援面板（导出诊断 /
  修复启动只清 SW 与缓存、绝不动站点数据）、动作日志 drain 折入
  Diag；此后每次部署基线都含救援层（机制全表见
  `plan_native_rescue.md` 第一节）。
- **去兼容与迁移通道（2026-11-24→25）**：备份 ZIP 转 Rust 原生
  格式（D1）、原版格式保留为一次性迁移通道（D2）、加载改为
  每次先归一后解析（D3 改判，标记闸门删除）；种子数据原生化、
  旧名别名与双读链逐项删除、模型类型化收口
  （`refactor_remove_compat.md`）。
- **诊断体系**：Diag 贯穿全部模块并按天归档、等级过滤、自动
  删除开关；panic 钩同步直写专用键，成为多次定因的第一证据面。
- **测试体系**：测试分工定案——全量回归在 Simular Box 跑、本机
  只做落码与编译级自检；T-1 原生夹具门禁 + T-3 脱敏迁移语料
  落地（2026-11-25），探针群纳入 run_all_tests 统一调度。

### 1.3 重点修复（定因一句话）

- **启动 trap / 点击死亡（2026-11-24）**：分组构建按标签归并时
  产生重复分组键、渲染楔死——改为分组键由构造唯一保证
  （e8b5e59），探针转正钉住故障输入条件。
- **加载失败（2026-11-24）**：存量旧形字段未归一即解析——加载
  改为先归一后解析，根治「备忘加载失败」（5ea5240）。
- **无痕模式被挡（2026-11-25，生产 ffdc0845e2）**：一切 install
  失败被误读为锁占用——改为按失败步位分类，真锁冲突才出占用
  页，其余分流会话 IDB 降级并明示不保存；默认存储池改先探后用，
  消除「写回默认值被当指纹静默换池」。
- **双栏定案（2026-11-22→24）**：独立模式须为真独立双栏容器
  （各自混排/滚动/渲染）；宽屏流式不跨栏（推翻 A-2 跨栏实现，
  回退两物理栏）；默认模式翻转为 independent。
- **天气双源恢复（2026-11-25）**：和风主用、彩云兜底的双 key
  链在模块化时丢失，Rust 版补回；彩云免费额度一度耗尽，链路
  本身已实证可用。
- **编辑链根治批（2026-11-23→25）**：打字增量同步落模型（80ms
  防抖 + 保险丝恢复）、标题聚焦事务、斜杠命令落点令牌化、
  导出快照式生成、editor.rs 按作用拆子模块（bridge/dispatch/
  model/ops/render/sheets/layers，批 14 二轮）。

### 2.3 重点修复（定因一句话）

- **0.9.43 点开闪退（proven，.ips 定案）**：单例初始化成环——
  语言单例 init 末行记诊断，诊断冻结往日归档时经日期格式化

- **拖拽拾不起（proven）**：长按手势被要求先等滚动手势失败，

- **标题胶囊横排溢出（proven）**：上限公式漏算页眉两段 8pt

- **图片页标题只显示「图片」（proven）**：原生附件表写入时

- **编辑页滚动卡死（proven）**：滚动偏移每帧变化连带整个块

  残余间歇冻结仍在跟进（见第五节）。
- **UniFFI 注释改动即闪退（proven，0.9.17）**：接口校验和把
  导出函数文档注释计入哈希，只重建库不重生绑定时真机首调

## 三、跨端共沉淀

### 3.1 架构与数据层

- **core 单一真源**：文档模型、MD 解析、备份格式收敛进
  moment-core，两端经 FFI/薄包装共用；编辑器交互逻辑不在
  共享面内（Web 在 JS 桥、原生在 Swift），数值规格必须从
  对方源码提取，不凭印象复刻（拖拽公式与胶囊量测两次实证）。
- **格式兼容改判**：字节兼容不再是硬约束，存量以展示为主，
  按最优形态重构 + 一次性迁移通道，兼容层彻底删除
  （`refactor_remove_compat.md` 三决策已全落）。
- **多人/同步/容量/iCloud 全部押后原生阶段**：Web 端按设备
  分区独立，数据迁移只靠 ZIP 导出导入；签名证书为测试签名
  （零 iCloud 容器授权），真 iCloud 等自有开发者账号接入。

### 3.2 验证纪律（结论 + 出处，全文见《教训沉淀》）

- 框架语义以框架源码实证为准，不凭直觉写进设计（Dioxus key
  一条，教训 1）。
- 手势类验证走真实触摸路径并看整串兼容回声；几何量测只认
  落定值，动画断言优先帧数口径（教训 2、3）。
- 探针先核对象身份与服务身份，地标随结构变更复审，命中类
  断言必须真实 tap，换身份路径必须有完整性断言（教训 4–9）。
- 结论只认与失败设备匹配的验证：无头/异引擎绿不等于真机过
  （教训 10）；归因被新证据推翻时当面更正（如首页置顶误判、
  闪退头号嫌疑被 .ips 推翻两例）。
- 证据分级 proven/inferred/unknown 贯穿全部报告；审计读数与
  源码冲突时以源码为准。

### 3.3 工程规范（2026-11-27 定稿，全文在 AGENTS.md 与仓库
《开发规范.md》）

- 改前通读相关完整源码；行为等价为底线取更优实现；问题从
  根源治理、不在消费方打补丁；拒绝代码堆积与上帝文件，按
  作用分类独立成文件（原生主文件为历史单文件结构，自 0.9.45
  起新增模块默认独立文件、存量逐批外拆）；尾巴先查无消费方
  再删、不留兼容孤儿；已解决项即时沉淀到对应文档。
