- 日期：2026-11-28
- 分支：`fix/safearea-census`，基线 = `fix/statusbar-root-fullbleed`
  尖端 `57c8316`（根满幅主修已在基线内，本线在其上续作）
- 范围：纯原生（用户裁定：Web 端已确认正常，env 顺手核取消）

## 0. 架构口径（用户补定，与状态栏「每页自答」同构）

安全区走**各面自答**：根层只给满幅画布与运行时 inset 来源，不由
单一容器替全树统一裁定几何；每页 / 每个浮动层按自身口径消费
inset 并自答。设置族 81、图片页 126 等既有分叉正是自答口径、保
留。普查逐面登记「谁在答、答的来源」；某面被上层强加且与自身口
径冲突的按异根处理、回该面自答。

## 1. 占位前提清单（几何改动前置，本线先行登记）

- **P1 满幅画布**：WindowGroup → StatusBarRootContainer
  `.ignoresSafeArea()` → 容器视图帧 = 窗口全幅；embed 托管视图背
  景显式 clear（SB-17 锁，基线 57c8316）。此后任一面拿到的
  `geo` 帧即窗口帧、`geo.safeAreaInsets` 即设备运行时 inset。
- **P2 inset 来源唯一性**：全仓 `safeArea` 命中仅 12 处、只在
  MomentApp.swift 与 MomentStatusBarEngine.swift 两文件（grep
  普查 proven）。来源三类：SwiftUI 环境 `geo.safeAreaInsets`
  （运行时）、引擎读容器视图 `view.safeAreaInsets.top`（运行时）、
  编辑器自量测 `ui.safeBottom`（单量测点回写）。
- **P3 自答类别**（逐面归类，见 §3）：
  - **W 窗口参照型**：公式/铺底假设帧 == 窗口。仅在 P1 下成立；
    0.9.67 根帧收缩时此类全破（同根）。
  - **S 安全区相对型**：在尊重安全区的容器内加相对内距，净位
    置对根帧收缩不变（补偿不变性）。
  - **E 显式读数型**：自读 `geo.safeAreaInsets.*` 加设计常量、
    锚在自身帧边缘；帧收缩时读数同步变小、净窗口位置不变。
  - **P 前提型**：平常量靠祖先前提把 safe 含入（「根 ZStack 底
    即 safe 底」），前提成立才对；前提须锁（SA77-5 + SA77-3）。
  - **F 帧参照型**：位置由同坐标系实测帧推出，不消费 inset。
  - **I 独立语境型**：系统 sheet 等独立呈现上下文，自带安全区
    语义，与根帧无关。
- **P4 带区色链**：面有满幅铺底层时带色 = 该层（开屏画布 / 各
  页根背景）；否则透出 window.backgroundColor——由启动铬面探针
  单点维护（开屏驻留期 = 开屏色、出开屏 = 根页色）。

## 2. 改前基线（0.9.67，现装机）

- 定因报告（fix_statusbar_root_fullbleed）像素实证：开屏蓝区 =
  安全区矩形，顶带 ≈59pt、底带 ≈34pt（iPhone 15 Pro 运行时
  inset），首页同病无感（白带与页色近）。此为 proven 基线。
- 本线开工时桥 `bridge_status` 回 app_offline（App 不在前台窗
  口），未取到新量测——不冒充；改后数值一律走 §8 装机复量格。

## 4. 根治落点

1. **同根（W 类 + 带色 + 引擎带高）**：唯一根 = 根内容树被框架
   收进安全区矩形。基线 57c8316 已在根容器层收口（满幅承载 +
   托管面 clear + SB-17 整行锚定锁）。本线复核确认：无第二处
   同根残留——W 类三面（开屏画布、图片页公式、引擎带高）的式
   形在 P1 下即为正确自答，不逐面改式。
2. **异根**：无。逐面核完未发现被上层强加且与自身口径冲突的
   面；两处「双叠 safe」（bgSheet、备份确认底表）经 Web CSS 逐
   字对账为原版公式移植，判设计口径、不动。
3. **本线代码落点**（防回潮，非逐面打补丁）：
   - verify_ios.sh 新增 **[77] SA77 组**五条前提锁（§7）。
   - MomentApp.swift 看门狗浮条补前提注记（纯注释：其底 16 此
     前是三条前提式底条中唯一未写明前提的一条，补齐后 SA77-5
     三条同锁）。
   - plan_selftest_coverage §7 登记三格装机复量（§8）。
   - 组号说明：本线在本基线暂编 [77]/SA77；原生画廊批在其分支
     另有 GA77 [77]，0.9.68 组版合并时须改号对账（先例 SR73 合
     并改 [75]）。

## 5. 写死字面普查

- 全仓布局面无设备 inset 字面：底 34 / 顶 47 / 底 59 形状的
  padding 恒 0（SA77-4 锁）。
- 唯一形似者：编辑 ••• 面板与导出面板的 `.padding(.top, 59)`
  ×2。其值 = 页眉几何和 7（页眉顶距）+ 46（钮高）+ 6（间隙），
  位于安全区相对坐标空间内（面板挂在尊重安全区的编辑根
  ZStack 上、坐标原点随 safe top 走），是帧参照的设计常量；
  与本机顶 inset 59 同值纯属巧合——换设备 inset 变化时该值不
  变、面板仍贴页眉下沿即为证伪判据。登记为 SA77-4 例外。

## 6. 键盘与横屏

- **键盘**：底让链单量测点（编辑根背景 GeometryReader，不忽
  略键盘的安全区）→ `ui.safeBottom` 两写（onAppear 直写 /
  onChange 写，SA77-2 锁写点数）→ kbPad 以 120ms 防抖落定
  （注释放着 0.9.56 latch 教训）；键盘可见性只由系统通知答，
  不再由 inset 派生。根帧变化对此链为补偿不变，机制无恙；
  数值对账归 §8 装机格。
- **横屏**：全仓无 leading/trailing inset 读点（grep 零命中，
  proven）——横向几何全部是安全区相对（系统 inset + 平内距）
  或帧参照，挖孔侧净空由系统在安全区内自动给出；满幅层用
  edges .all、宽屏判定（homeWide / 编辑双栏）为尺寸运行时判
  定。判正常/设计口径；实际净空与带色归 §8 横屏装机格。

## 9. 结论分级

- **proven**：根帧收缩为唯一同根（像素 + 源码双证，定因报告）；
  W/S/E/P/F/I 全面归类与逐面数值口径（源码逐行核 + Web CSS 对
  账）；无设备字面（grep 普查）；横向零 inset 读点。
- **inferred**：S/E 类「补偿不变性」为 SwiftUI 布局语义推论，
  与 0.9.67 装机表现（内容位置无异常实报、仅带区有报）相符。
- **unknown（待装机）**：满幅后各面带区像素、图片页 availH 数
  值、横屏净空、kbPad 数值——全部登记 §8，不冒充已验。
