## 2. 逐类根治手法与落点（MomentApp.swift）

**类 A · 字形封顶（固定槽内的缩放字形封顶至槽宽，槽与布局几何不动）**——统一式 `min(同源 @ScaledMetric, 槽宽)`，共 8 类位点（DT36-2 计数锁）：
- 完成胶囊椭圆：`.title2` → `min(f22, 34)`（槽 46、玻璃裁切；帧公式 46↔92 未动）
- 菜单行图标（EditorView.menuItem）：`.title3` → `min(f20, 24)`；斜杠行图标同式（共 2 处）
- 双栏行图标：`.body` → `min(f17, 24)`
- 待办勾选字形（BlockRow）：`.title2` → `min(f22, 30)`（命中槽 44 不动）
- SetRow 图标：→ `min(f16, 24)`；BackupRow 图标：→ `min(f17, 28)`；天气可见性图标：→ `min(f15, 28)`；手势图示：`f25` → `min(f25, 25)`（图示封顶 = 槽宽）

**类 B · 定高改最小高（文字钮/胶囊改内容驱动下限）**：
- 备份确认底表双钮：`frame(height: 44)` → `frame(minHeight: 44)` ×2（全文件定高 44 归零）
- DiagLogPage 导出胶囊：`frame(height: 46)` → `frame(minHeight: 46)`
- 错误徽章钮：定尺寸圆 36×36 + RoundedRectangle(18) 底 → `.padding(.horizontal, 7)` + `frame(minWidth: 36, minHeight: 36)` + Capsule 底（单数字默认档与旧圆逐值等价、多位计数横向生长）

**类 C · 限高内滚（面板/底表帧高 = min(实测内容高, 视口 − 边距)，超高内滚）**——与菜单 menuPanelH/bgSheet 同一实测回写机制，不另起第二套：
- bgSheet：根 VStack 外包 ScrollView + onGeometryChange 回写 `EditorUI.bgSheetH`，帧高 = min(实测 ?? 估值 240/300, viewH − 28)；overlayCard 挂外层固定
- 导出面板：同机制（`EditorUI.exportPanelH`，上限 viewH − 67）；定位内距（top 59 / trailing 16）留在帧外
- 链接表单：改 `linkFormPanel(maxH:)`，斜杠层把既有 maxH 传入，ScrollView + `.frame(maxHeight: maxH)`，卡面挂外层；表单自然高默认约 170 恒低于 maxH、逐值不变

**类 D · 容器尺寸并入同一缩放度量（与标题胶囊 delta 手法同源）**：
- ListBlockView：新增 @ScaledMetric(relativeTo:.callout) 三枚——markerW 20、indentBullet 19、indentOrdered 22，标记框与嵌套缩进改引用之
- MdBlockView List 支：`markerW = baseSize * 1.125`，标记框改 markerW、文起点间距公式 `* baseSize - 18` → `* baseSize - markerW`（J20-12 改判留痕，见 §6）
- 导出徽章盒：`frame(width: 34, height: 34)` → `frame(width: f34, height: f34)`（f34 = caption2 同源 @ScaledMetric，默认恒 34）
