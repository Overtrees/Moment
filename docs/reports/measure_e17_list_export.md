## 残余面定论（proven，实测）

1. **有序编号被重编**：3/4/5 → 1/2/3。模型 numbered-list 节点无 start 字段，导出侧无从恢复——修复须模型层存 start，属模型层改动，单独评审。
2. **行内标记丢失**：`**粗体**`、`[链接](url)` → 纯文本。list_md 取 item.plain_text() 所致；导出侧补行内 MD 序列化可解，不涉模型层，但与第 1 条同属「列表节点回生源文本」议题，宜同评审一并定方案。
3. **嵌套子项文本在父项行重复**（scope 未预估、实测新增）：父项行尾拼出「子项一子项二」——plain_text() 全递归含子列表文本，子项内容出现两次。导出侧可单独修（父项只取自身行内文本、跳过子列表子节点），不涉模型层。
4. 嵌套缩进两端同为 2 空格，无差异。

结论：残余面实存且含内容重复（第 3 条），不可忽略关单；整组修复以第 1 条为纲需动模型层（numbered-list 存 start），按核定纪律停在实测、不在本批硬改，留单独评审（含第 2/3 条导出侧修法一并定）。
