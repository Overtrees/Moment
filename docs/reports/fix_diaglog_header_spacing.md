## 二、黑卡间距对齐设置页

### 量测方法

用户两张真机截图（1179×2556 @3x，393×852pt，顶安全区 59、底 34）像素量测：黑卡以纯黑段行/列扫描定边；设置页玻璃卡以行均亮度（避文字列）+ 白段扫描 + 视觉定位三法互证。源码合成值与实测逐项对账。

### 设置页截图状态定性（proven）

设置页截图处于**上滑 ≈45pt** 的滚动状态：未滚动口径反推——首组头块 = SectionHeader（topPad 4 + 字高 ≈18 + bottom 6 = 28），首卡未滚动顶 = 根帧 59 + 内容框顶 126 + 28 = **213**；实测首卡顶 169、首组标签中心 151.7（未滚动 198）、第二卡顶 297.7（未滚动 ≈345），三处偏移 44 / 46 / 47 一致（±2 为字高估算误差）。页头不随滚动：胶囊顶实测 70.3 = 59 + ChromeView 顶距 11，圆钮顶 ≈66 = 59 + 7，两页同值。

**结论**：设置页未滚动时内容顶 = **185**（= 59 + 126），与日志黑卡顶逐值相同——用户观感差来自截图滚动状态，不是两页口径差。
