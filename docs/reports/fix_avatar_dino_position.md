## 三、落码（MomentApp.swift · AvatarView）

构图常数单点（相对圆径 D，注释含推导）：

- `dinoCanvasScale = 0.8891`（= 0.698 ÷ 402 × 512）
- `dinoOffsetX = 0.0538`（= 0.191 − 79 × 0.698 ÷ 402）
- `dinoOffsetY = 0.2346`（= 0.337 − 59 × 0.698 ÷ 402）

回退分支改为 `DinoView(size: size * dinoCanvasScale).offset(x: size * dinoOffsetX, y: size * dinoOffsetY).frame(size×size, alignment: .topLeading).glassControl(radius: Radius.pill)`——glassControl 的圆形裁切把越底 0.052D 的下巴/颈部裁在圆下缘，与参考图齐平形态一致。

落码后复算：宽 0.698 / 左距 0.191 / 顶距 0.337 / 底边 1.052D（越圆底裁切）/ 可见中心 dy +0.169（参考 +0.163，差 0.006 在量测容差内）。

**影响面**：
- 受影响：默认恐龙回退面——首页页眉头像、编辑页标题坞头像（同一组件、同常数，两处自动同值同源）。
- 不受影响：用户自定义头像路径（avatars 通道，整圆贴图分支）逐字未动；头像点按行为（首页进设置、编辑页换图）未动；圆框位置/大小/页眉布局未动。
- Web 侧未动：新构图与 Web 现行口径（size−8 底对齐）自分叉，Web 是否跟进留主线裁量，本批只登记。
